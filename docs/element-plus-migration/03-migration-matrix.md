## 2. Oportunidades Críticas de Eliminação de Código

1. **Eliminação da Dependência `reka-ui`:**
   - Com `ElSelect`, removemos `reka-ui` do `package.json`, eliminando 10 componentes importados e 120 linhas de CSS customizado em `theme.css`.
2. **Eliminação do Hack de MutationObserver em `AppToaster.vue`:**
   - Com `ElNotification` / `ElMessage`, a biblioteca gerencia o z-index centralmente. Eliminamos 20 linhas de lógica frágil de mutação no DOM.
3. **Redução Drástica dos Monolitos:**
   - `AnalysisPanel.vue` reduz de 1.579 linhas para um orquestrador enxuto de ~200 linhas com 5 subcomponentes especializados.
   - `SettingsPanel.vue` reduz de 1.134 linhas para ~180 linhas com 3 formulários modulares.
